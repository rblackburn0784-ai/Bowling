# Gutter Saints Bowling — v2.9.3 RC Final Pre-Push Audit

**Status:** Code candidate for GitHub CI and Discord staging. Not certified for a public release.
**Audited source:** `Gutter_Saints_Bowling_v2.9.3_RC_With_Updated_PNGs.zip`, with the fixes below applied before the proposed push.
**Current GitHub baseline at audit:** v2.9.2 (`8985c5e25216ade600038d5a420af40ea9a74adc`). No GitHub write was performed.

## Two issues found and fixed

1. **League administration lacked an independent runtime permission guard.** `cogs/league.py` previously used only `@app_commands.default_permissions(manage_guild=True)` for write commands. Added a Cog-level runtime check requiring `Manage Server` or Administrator on competition mutation commands, while preserving public access to the read-only `/league_table` and `/season_dashboard` commands. Added a static regression test plus a Discord-dependent runtime test (CI gate).
2. **The older `/fixture_start` slash command skipped live introductions and controls.** It now calls the same `post_match_controls(..., introduce=True)` used by Competition Director, and recognises a championship fixture to use `finals` presentation. Added a static regression test. No scoring, physics or database schema changes.
