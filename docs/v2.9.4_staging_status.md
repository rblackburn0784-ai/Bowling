# v2.9.4 consolidation staging

This branch stages the v2.9.4 game-completion code fix. It is **not** the complete release. The full local package also includes a revised showtime graphics renderer and five large binary PNG assets, which have not been uploaded to GitHub.

Do not merge as a complete v2.9.4 release until those resources are incorporated and checked. The code ensures both friendly and ranked matches can call their closing graphical scorecard; it does not change the bowling engine or scoring.
