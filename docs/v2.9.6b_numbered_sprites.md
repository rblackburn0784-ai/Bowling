# v2.9.6b — Numbered sprite discovery fix

Fix for character folders `01_cardigan_classic` through `20_metallic_silver` not appearing in the Discord Create Bowler and Edit Bowler dropdowns.

- Allow digits at the beginning of sprite folder names.
- Prioritise 20 complete numbered sprite folders over legacy fallback characters.
- Preserve existing stored `the_dude`/`jesus` selections even when 20 new characters exist.
- Require readable `1.png` through `5.png` in every selectable folder.
- Character previews and animations use the same verified sprites; no score/career changes.

**Artwork still must be uploaded separately.** At the time this fix was prepared, GitHub `main` only contained `assets/sprites/the_dude` and `assets/sprites/jesus`. The new numbered character folders are visible in the user's local project but are not present on GitHub. Place them in `assets/sprites/<01...20_name>/1.png...5.png`, then commit and push those directories. Restart the Discord bot afterward; its sprite cache is per-process.

Run: `python -m unittest discover -s tests -p test_v296b_numbered_characters.py -v`.

The change does not bundle any new character image assets.
