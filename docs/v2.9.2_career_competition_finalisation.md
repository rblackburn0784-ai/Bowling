# Gutter Saints Bowling v2.9.2 — Career & Competition Finalisation

Built on v2.9.1 (`main` commit `1bd886debddfcf0ee790fda0a68db1893942eebb`).

## Scope

This is a career/administration release, **not a physics or visual redesign**. Living Lanes 2.0, all three broadcast panels, 23-stage GIF playback, character frames, ball art and existing 10-pin scoring are unchanged. The six attributes remain Accuracy, Consistency, Spin, Nerves, Style and Flair, with the 90-point/5–25 initial allocation and earned career range 1–50. The existing XP→rank curve and established results are preserved to avoid retroactive changes.

### Career balancing and progression integrity

- Protect rank and the six earned attributes from `update_owned_bowler` identity edits (only name and handedness can change through that helper). This closes a potential progression bypass without changing the model.
- Career read model displays rank title, XP to next rank, progress percentage, game average, high game, achievements, honours and all six skill values.
- Cosmetic exhibition XP is shown separately and **does not count toward rank**.
- Twelve one-time **career milestone** achievements: first recorded game; games 10/25/50/100; strikes 50/100; spares 50; clean games 5/10; split conversions 5/20.
- Milestones are based on committed `bowler_stats` and granted inside the same transaction as game results. Failed finalisation rolls them back; retries don't duplicate them. Exhibition challenges do not grant career milestones.
- Normal scoring/XP/rank and automatic delivery attribute evidence are preserved to maintain save compatibility. The offline balance test remains a mandatory release gate.

### Career records and achievements

- New read-only category leaderboards: average, high game, 300s, strikes, spares, split conversions, clean games and games played.
- **Average requires at least three completed games**, reducing one-game leaderboard distortion. Equal records use deterministic tiebreak ordering.
- Shared records backend powers admin Records and public Career Records; `/leaderboard` adopts the qualification threshold.
- Manual awards use one transactional function with input validation, duplicate detection, audit log and correct award totals. `/award_give` now enforces server-administrator/Manage Server permission in the interaction handler, not merely Discord command defaults.

### Tournament and competition administration

- Tournament honours ceremony now grants every bowler honour, the career timeline and team championship/finals counters **atomically**. Re-running cannot duplicate counters or awards, even with an empty winning roster. Existing champion honours are respected on first migration.
- Additive `tournament_honour_runs` marker records a successfully processed championship ceremony. Existing save data is never rewritten or deleted.
- Tournament Director gains **Pause / Resume** (audited) and read-only **Integrity Check** with recoverable-match channel IDs. Pausing blocks *new manual results*, but doesn't abort an already-running bowling session or its safe completion.
- Manual tournament results cannot override a pending match with a saved/recoverable Discord session. Invalid winners/scores are still rejected by the existing guard rails.
- Competition Director's admin Records page offers a read-only competition health summary for completed fixtures missing scores, negative scores, invalid winners and incomplete in-progress fixtures. It does not silently alter brackets.

### Menu consistency

- Admin Home and Director's Main Menu preserve administrator navigation buttons.
- Public Main Menu gains a Career Records entry available without admin permissions.
- Career view gains Career Progress, and every new view offers Main Menu navigation.
- New admin health/records views continue using the existing guarded navigation model.

## Upgrade / rollback

1. Back up `data/gutter_saints.db`, the existing production PNG folders and `assets/` manifests.
2. Install code without replacing `data/` or your existing artwork. Start the bot; `init_db()` adds only the `tournament_honour_runs` table.
3. Verify `/menu` (Career Records and My Bowler → Career Progress), admin → Records, and legacy Tournament Director Pause/Resume/Integrity Check.
4. Complete a new regular game, verify one debut achievement, restore/retry it and ensure it awards only once. Repeat one trophy ceremony and ensure no duplicates.
5. Before public release: verify these Discord controls on your beta server, run full Python 3.13 CI with `discord.py` installed and inspect real camera PNGs/celebrations.
