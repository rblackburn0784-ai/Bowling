# v2.9.6d — Single-message menu navigation

The first `/menu` slash command creates one private Discord response. Subsequent menu choices edit **that response** instead of posting additional ephemeral boxes.

Covered:
- Main Menu, My Bowler, Edit Bowler, My Stats, Achievements, Arsenal, Career Records, Browse Bowlers, My Competition, Gutter Gazette and Season Hub.
- Player career submenus, sprite previews and selection, season submenus, competition and archive navigation, return-to-main buttons, and challenge composer confirmations.
- Existing images/embeds cleared on navigation; preview art replaced only when the destination needs it.
- Public challenge invitations and live-game broadcasts remain independent channel messages.
- Modal-submit interactions edit the parent when Discord includes a message; otherwise fall back to one private response.

Code changes are limited to menu navigation; scoring, rankings, physics, assets and database records are unchanged.

Tests: `python -m unittest discover -s tests -p 'test_*.py' -v`.

The patch was previously validated with 18 focused tests. Live Discord verification is still required to confirm ephemeral-message editing works on the intended clients.
