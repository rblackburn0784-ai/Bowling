# v2.9.6a — Bowler Sprite Selection (GitHub staging)

## Added
- Dynamic character selector discovers up to 20 complete five-frame sprite sets.
- Selected character and preview shown while creating a bowler.
- Main menu has Edit Bowler; career profile has Change Sprite.
- My Bowler shows an image and the assigned sprite.
- Only the linked owner can persist a changed sprite.
- Appearance edits never change rank, career stats, progression or game RNG.
- Source supports new packs with `assets/sprites/<key>/1.png` through `5.png`.
- Optional `cheer.png` is used when present.

## Important release status
This branch builds on **release/v2.9.6-staging**. Prior 2.9.4–2.9.6 branches have not been merged into `main`. GitHub still lacks the image files from the local complete archive, including scoreboard start/end backgrounds and camera plates. Only The Dude and Jesus are complete in the source ZIP; it does not contain 20 unique sets.

The connected GitHub tool can commit text, but cannot directly import the binary PNGs from local `Bowling_v2.9.6a_Sprite_Selection_FULL.zip` into the Git objects. **Do not merge this branch as a full visual release** until all artwork is uploaded and the complete bot has passed Discord integration tests.

For full publication, use the locally created FULL ZIP to supply all source/artwork with a normal local Git push and verify no `.env`, private database, virtual environment or generated runtime files are committed.
